# ZScope website

Source of the ZScope project website (React + Vite + Tailwind CSS). Published with GitHub Pages.

## Run locally

    npm install
    npm run dev          # http://localhost:5173/

## Preview the production build (exactly what GitHub Pages will serve)

    npm run build
    npm run preview      # http://localhost:4173/ZScope/

The Pages base path is set by `BASE` in `vite.config.js`.
