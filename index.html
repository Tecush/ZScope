ZScope: Professional EIS Circuit Modeling & Fitting

Electrochemical Impedance Spectroscopy simulation, advanced fitting, and Bayesian uncertainty quantification — all in one intuitive desktop application.

Download ZScope v1.0 (Windows)

Also available for macOS & Linux • Trial mode • Full source on GitHub

ZScope is a standalone scientific application for Electrochemical Impedance Spectroscopy (EIS) modeling, simulation, and experimental data fitting. Built with PyQt6 and optimized for performance, it provides researchers and engineers with professional-grade tools previously available only in expensive commercial software.

✨ Key Features

🧩 Interactive Circuit Builder

Drag-and-drop components (R, C, L, CPE, Warburg, Gerischer, Transmission Line) with real-time netlist generation. Visual wiring with automatic topology detection and dead-end pruning.

📈 Live Simulation

Instant Nyquist, Bode magnitude, and Phase plots as you adjust parameters or frequency range. Vectorized MNA solver delivers 20-30× speedup over per-frequency loops.

📊 Advanced Fitting Engine

TRF optimizer with Latin Hypercube multi-start, robust loss functions (soft_l1), frequency sub-band filtering, and AIC/BIC model selection. Matches ZView/NOVA-grade capabilities.

🧠 Bayesian MCMC Uncertainty

Full posterior sampling with emcee, credible intervals, convergence diagnostics (N/50τ, Gelman-Rubin R̂), and predictive uncertainty bands on plots.

🎨 Theme-Aware UI

6 built-in themes (Dark, Light, Nord, Solarized, Dracula, Monokai) with dynamic plot/canvas styling. All dialogs and panels adapt automatically.

🔍 AI Circuit Proposal

Auto-generate ranked circuit topology suggestions from experimental data using feature extraction, template matching, and AIC-penalized scoring.

📚 Documentation & Support

Getting Started

  1. Load a preset — Select "Randles" from the Presets menu to see a standard circuit.
  2. Adjust parameters — Double-click any component to open the Parameter Panel.
  3. Run simulation — Click ⚡ Run Simulation (or press F5) to generate plots.
  4. Load experimental data — Use 📂 Load Data to import CSV, MPT, DTA, or Excel files.
  5. Fit your model — Click ⚙ Fit to optimize parameters against experimental data.

Key Concepts

  • Circuit Notation: Use syntax like Rs-[Rct/Cdl] to build circuits programmatically.
  • Kramers-Kronig Validation: Run 🔬 KK Check to verify data quality before fitting.
  • Weighting Strategies: Choose modulus (default), proportional, or unit weighting for fitting.
  • Bayesian MCMC: Enable uncertainty quantification with credible intervals and predictive bands.
